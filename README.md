# 🎯 ب لبن قطر — تقييم الأداء (PWA)

نظام تقييم أداء فروع ومديري ب لبن قطر — مدير التشغيل: **بِلَال الأَنْصَارِي / BELAL AL-ANSARY**

تطبيق ويب تقدمي (PWA) يعمل على الديسكتوب والموبايل، يدعم العمل بدون إنترنت، قابل للتثبيت كتطبيق محلي.

## 🚀 طرق النشر

### الطريقة 1: GitHub Pages (الأسهل والمجانية)

1. **أنشئ Repository جديد** على GitHub باسم مثل `blaban-qatar`
2. **ارفع كل الملفات** (سحب وإفلات في صفحة الـ repo)
3. اذهب لـ **Settings → Pages**
4. تحت **Source**: اختر `Branch: main` و `Folder: / (root)`
5. اضغط **Save**
6. خلال دقيقة سيظهر الرابط: `https://[username].github.io/blaban-qatar/`
7. شارك الرابط مع فريق العمل!

### الطريقة 2: Vercel (احترافية ومجانية مع SSL)

1. سجّل في [vercel.com](https://vercel.com) (مجاني)
2. اضغط **Add New → Project**
3. ارفع المجلد كـ ZIP أو اربطه بـ GitHub repo
4. اضغط **Deploy** — انتهى!
5. ستحصل على رابط مثل: `https://blaban-qatar.vercel.app`

### الطريقة 3: Netlify (بديل مماثل)

1. سجّل في [netlify.com](https://netlify.com)
2. اسحب مجلد `blaban-pwa` لمنطقة الإفلات
3. خلال ثوانٍ سيُنشر التطبيق

### الطريقة 4: استضافة محلية (للاختبار)

```bash
# Python (موجود على معظم الأجهزة)
cd blaban-pwa
python3 -m http.server 8000
# افتح: http://localhost:8000

# Node.js
npx serve blaban-pwa
```

## 📱 تثبيت التطبيق على الأجهزة

### الديسكتوب (Chrome / Edge / Brave)
1. افتح الرابط
2. ستظهر أيقونة "تثبيت" 📥 في شريط العنوان (يمين أعلى)
3. اضغط عليها → "تثبيت"
4. سيُفتح التطبيق في نافذة مستقلة وتظهر أيقونة على سطح المكتب

### الموبايل Android (Chrome)
1. افتح الرابط
2. سيظهر بانر "تثبيت التطبيق" أسفل الشاشة
3. أو من القائمة (⋮) → "تثبيت التطبيق"
4. ستظهر الأيقونة على الشاشة الرئيسية

### الموبايل iOS (Safari)
1. افتح الرابط في **Safari** (ضروري — لا يعمل في Chrome على iOS)
2. اضغط زر المشاركة 🔄 (مربع مع سهم لأعلى)
3. اختر **"Add to Home Screen"** / **"إضافة إلى الشاشة الرئيسية"**
4. اضغط **Add**
5. ستظهر الأيقونة على الشاشة الرئيسية كتطبيق محلي

## ☁️ مزامنة البيانات بين الأجهزة (Firebase)

التطبيق يدعم مزامنة فورية بين كل الأجهزة عبر Firebase Realtime Database (مجاني لحجم متوسط).

### إعداد Firebase (مرة واحدة)

1. اذهب إلى [console.firebase.google.com](https://console.firebase.google.com)
2. اضغط **Create Project** → اختر اسم مثل "blaban-qatar"
3. أضف **Realtime Database** (ليس Firestore):
   - من القائمة: Build → Realtime Database
   - اختر **Start in test mode** للبداية
4. أضف **Authentication**:
   - من القائمة: Build → Authentication → Get Started
   - فعّل **Anonymous** sign-in
5. اذهب لـ **Project Settings (⚙️) → General → Your apps**
6. اضغط أيقونة **Web (</>)** → سجّل التطبيق
7. انسخ كائن `firebaseConfig` كاملاً (يحتوي apiKey و databaseURL وغيره)

### تفعيل المزامنة في التطبيق

1. افتح التطبيق
2. اضغط **☁️ مزامنة** في الـ Header
3. الصق الـ JSON الذي نسخته
4. اختر اسم workspace موحد لكل الفريق (مثل `blaban-team-2026`)
5. اضغط **حفظ** → ستبدأ المزامنة فوراً!
6. كل جهاز يستخدم نفس الـ workspace سيرى البيانات في الوقت الفعلي

### قواعد الأمان (تحديث بعد الاختبار)

في Firebase Console → Realtime Database → Rules، الصق:

```json
{
  "rules": {
    "workspaces": {
      "$workspace_id": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
```

## 🔐 نظام الحماية

- **القراءة مفتوحة للجميع**: كل من يفتح التطبيق يرى البيانات للقراءة فقط
- **التعديل محمي بـ PIN**: مدير التشغيل فقط يقدر يعدّل التقييمات والتوصيات
- **الجلسة 15 دقيقة**: بعد إدخال الرمز، التعديل مفتوح لمدة 15 دقيقة
- **بصمة Face ID**: على الأجهزة المدعومة، إعداد بصمة كبديل سريع للرمز

### أول استخدام
1. اضغط **🆕 الأمان** في الـ Header
2. أدخل رمزاً جديداً (4 أحرف على الأقل) — احفظه!
3. (اختياري) أضف بصمة لتسجيل دخول سريع

## 💾 النسخ الاحتياطي

التطبيق يحفظ نسخة احتياطية تلقائياً في الـ localStorage. للنسخ اليدوي:

1. اضغط **🔐 الأمان** → **📥 تنزيل نسخة احتياطية**
2. سيتم تنزيل ملف JSON
3. لاستعادة: نفس القائمة → **📤 استعادة من ملف**

## 🌐 يعمل بدون إنترنت

بعد فتح التطبيق أول مرة (مع إنترنت)، الـ Service Worker يخزّن التطبيق محلياً.
- ✅ يعمل بدون إنترنت بالكامل
- ✅ المزامنة تتم لما يرجع الإنترنت
- ✅ كل البيانات محلية + Firebase (مزدوج)

## 🛠️ Troubleshooting

### "التطبيق لا يثبت"
- تأكد أن الرابط HTTPS (لا يعمل عبر file://)
- على iOS: استخدم Safari فقط
- جرّب تحديث الصفحة

### "البيانات لا تتزامن"
- تأكد من إعداد Firebase config
- تأكد من تفعيل Anonymous Auth
- استخدم نفس الـ workspace name في كل الأجهزة

### "ظهرت رسالة Service Worker error"
- نظّف الـ Cache من Settings → Site Data
- أعد تحميل الصفحة (Ctrl+Shift+R)
